# Actividad 6 · Catálogo interactivo con JavaScript

Actividad de la Semana 6 de Desarrollo Web: catálogo de productos dinámico construido con JavaScript, manipulando el DOM y trabajando con arrays de objetos.

**Ejercicios 1 a 5 resueltos.

## Consigna

A partir de un array de productos ya definido, completar las funciones de `js/app.js` para:

1. Mostrar los productos en tarjetas dinámicas.
2. Filtrar los productos disponibles (stock > 0).
3. Filtrar los productos de categoría "Notebook".
4. Mostrar solamente los primeros 4 productos.
5. Buscar productos por nombre, sin distinguir mayúsculas/minúsculas.

## Tecnologías utilizadas

- HTML5
- Bootstrap 5
- JavaScript (DOM, `forEach()`, `filter()`, `slice()`, `includes()`)
